# SonicT Daily Reporter

这是一个可直接以“加载已解压的扩展程序”方式导入 Chrome 的 MV3 插件。

## 使用

1. 打开 `chrome://extensions/`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择本项目文件夹。
4. 点击扩展图标，插件会打开一个独立小窗，用来维护报表网址、账户、密码、解析板块和输出模版。
5. 点击“开始”，插件会按列表顺序打开并选中报表 tab，自动登录并按模版输出解析结果。

## 通配符

- `[code]`：网页编号，当前按列表索引输出。
- `[t1]`：第 1 个解析板块名称，`[t2]` 为第 2 个解析板块。
- `[t1,h1]`：第 1 个解析板块的第 1 列列名。
- `[t1,r-1,c1]`：第 1 个解析板块中昨日行的第 1 列数据，`r0` 为今日，`c3` 为第 3 列。

日期按浏览器本机日期和 `r` 偏移计算，行头格式示例：`2026-05-28(四)`。

## 说明

- 任务日志和输出会保存在 `chrome.storage.local`，popup 关闭后重新打开仍可查看。
- 默认解析板块和默认输出模版只是初始配置，可以在小窗中修改。
- 为了支持用户维护任意报表网址，扩展申请了 `<all_urls>` 主机权限。
- 账户和密码只保存在本机 Chrome 扩展存储中。
