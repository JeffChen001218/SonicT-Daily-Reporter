# SonicT Daily Reporter

这是一个可直接以“加载已解压的扩展程序”方式导入 Chrome 的 MV3 插件。

## 使用

1. 打开 `chrome://extensions/`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择本项目文件夹。
4. 点击扩展图标，插件会打开一个独立小窗，用来维护报表网址、账户、密码。
5. 点击“开始”，插件会按列表顺序打开并选中报表 tab，自动登录并解析昨日数据。

## 当前解析目标

- “经营数据”板块：定位昨日行，输出 `消耗`、`毛利`。
- “核心指标”板块：定位昨日行，输出 `d0`、`PV`、`渗透率-TT`、`渗透率-GG`。

目标日期按浏览器本机日期减 1 天计算，行头格式示例：`2026-05-28(四)`。

## 说明

- 任务日志和输出会保存在 `chrome.storage.local`，popup 关闭后重新打开仍可查看。
- 为了支持用户维护任意报表网址，扩展申请了 `<all_urls>` 主机权限。
- 账户和密码只保存在本机 Chrome 扩展存储中。
